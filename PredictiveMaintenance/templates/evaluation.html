Model Evaluation Overview

This page presents the experimental evaluation of machine failure prediction models trained using the AI4I 2020 Predictive Maintenance dataset. Logistic Regression, Decision Tree and Random Forest were compared using the original training data and SMOTE-based resampling. Precision-recall analysis, confusion matrices and classification-threshold experiments were also conducted.

Important evaluation detail: The experiments below use 8,000 training records and 2,000 test records. The test set retains its original class distribution, including 68 machine-failure cases. SMOTE was applied only to training data.

6. Results and Discussion

The dataset contains 10,000 records, of which 9,661 represent healthy machines and 339 represent machine failures. The minority-class proportion is therefore 3.39%, making class imbalance an important consideration during model development and evaluation.

Three classification algorithms were compared: Logistic Regression, Decision Tree and Random Forest. Random Forest trained on the original training data achieved 96.90% accuracy and an ROC-AUC of 94.38%, along with the highest Average Precision of 0.5394 among the six configurations.

Applying SMOTE increased failure recall for both Decision Tree and Random Forest in these experiments. However, it also increased false positives and reduced overall accuracy. This demonstrates that improving failure detection can involve a trade-off with unnecessary maintenance alerts.

Threshold experiments showed that reducing the classification threshold increased recall while generally decreasing precision. A threshold of 0.30 produced the highest F1-score among the tested values.

7. Conclusion

Random Forest trained on the original data is the current baseline because it achieved the strongest overall results across several evaluation measures in the reported experiments.

The comparison also highlights the importance of failure recall, false alarms, class imbalance and threshold selection. Further validation is needed before selecting the final model configuration and deploying the system in a real industrial environment.
